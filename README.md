# HTML e CSS - 2026
Este projeto foi desenvolvido como atividade escolar, com fins pedagógicos, cujo principal objetivo é colocar em prática os conhecimentos adquiridos sobre *CSS* e desenvolvimento web.

O site foi criado para explorar e demonstrar a utilização do CSS na estilização de páginas web, trabalhando conceitos como cores, fontes, layouts, organização de elementos e personalização visual.
